# Homebrew status

HOOP does not currently publish a Homebrew cask or a signed Mac download. Build the Mac app from source using [BUILD.md](BUILD.md).

A HOOP Homebrew tap can be added after the first Mac release is available from [this repository](https://github.com/GaneshVarma1/HOOP/releases). Any future cask should point to a HOOP release asset and use the HOOP app name and icon.
